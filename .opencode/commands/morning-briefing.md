You are preparing the General Manager's morning briefing. Use the **hotel-gm-briefing** skill.

Arguments: `$ARGUMENTS`
- If empty, generate the briefing for today's date at the default property.
- If a property name is given, generate for that specific property.
- If a date is given, generate the briefing for that date.

Do the following:

1. Load last night's night audit data, today's arrivals and departures, and recent guest feedback.
2. Compile the executive digest covering: last night's performance (occupancy, ADR, RevPAR, revenue), today's operational overview (arrivals, departures, VIPs, room availability), guest experience snapshot (complaints, scores, pending recovery), and any heads-up items.
3. Keep it concise — one screen, scannable, action-oriented. GMs have 5 minutes to read this before their first meeting.
4. End with the top 3 action items for today, prioritized by urgency and guest impact.

Present the briefing in a professional format suitable for forwarding to the executive team.
